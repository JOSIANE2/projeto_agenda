# Agenda de contatos

Formulário em HTML, CSS e JavaScript. Adiciona nome e telefone à tabela e rejeita nomes repetidos, ignorando diferenças de maiúsculas e espaços externos. Telefones são mantidos como texto.

## Executar
Abra index.html em um navegador, mantendo main.css e main.js na mesma pasta.

## Limitações
Os dados ficam apenas na página e são perdidos ao recarregar. Não há edição, exclusão, autenticação ou validação de formato telefônico.
